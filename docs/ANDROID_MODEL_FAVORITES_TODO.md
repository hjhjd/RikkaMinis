# Android 模型收藏功能 TODO

> 创建日期：2026-08-14
>
> 状态：功能施工完成；完整编译受沙箱 AAPT2 架构不兼容阻断
>
> 目标：在聊天模型选择器中允许收藏具体模型，并将收藏模型置于模型组和服务商列表之前。

## 实施原则

- 收藏属于模型条目，不复用服务商收藏状态；
- 收藏持久化到 ProviderConfig JSON 镜像与 provider.db；
- 刷新远端模型列表时保留已有收藏；
- 收藏模型在选择器顶部独立展示，同时保留在原服务商列表中；
- 点击星标只切换收藏，不选择模型、不关闭选择器；
- 不改动工作区现有终端/NDK 相关未提交内容。

## 验收标准

1. 收藏模型后无需关闭选择器即可出现在顶部；
2. 重启、修改其他服务商配置、刷新模型列表后收藏不丢失；
3. 取消收藏后立即从顶部区移除，原服务商列表条目仍存在；
4. 星标操作不会改变当前会话模型；
5. 老数据库升级后所有模型默认未收藏且原数据完整；
6. 搜索时匹配的收藏模型仍优先显示。
